# Lots 7-8-9 — Build, Launcher/VSCode, abstractions UI (Core + tests)

Cumulatif sur les lots 0-6. Aucun changement de .csproj.

## Lot 7 — Build (PlatformIO + ESP-IDF + aiguilleur)
```
Core/Services/IBuildBackend.cs        # Build/Flash/Monitor/Clean communs
Core/Services/IPlatformIOService.cs + PlatformIOService.cs   # pio run / run -t upload / device monitor / run -t clean
Core/Services/IEspIdfService.cs      + EspIdfService.cs       # idf.py via shell (source export.sh|call export.bat)
Core/Services/IBuildService.cs       + BuildService.cs        # route selon project.IsEspIdf
```
- Tout via IProcessRunner + IToolLocator (aucun pio.exe/git.exe en dur, ArgumentList).
- **ESP-IDF portable et vivant sous Linux** : bash -lc "source '<export.sh>' && idf.py -C '<dir>' <sub>"
  (Windows : cmd /c "call <export.bat> && idf.py ..."). Port série -p depuis les Paramètres.
  Détection ports Linux : /dev/ttyUSB*, /dev/ttyACM*.
- Tests : arguments exacts de chaque commande, dispatch PIO/ESP-IDF, wrapper shell IDF, port série.
