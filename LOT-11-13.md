## Ce qui est couvert (Core, testable)
- **BGR565 AKA** : Pack/Unpack (rouge=0x001F, bleu=0xF800, vert=0x07E0, blanc/noir),
  et RGB565 standard (rouge/bleu inversés) — vos vecteurs de référence, exacts.
- **Transparence** : alpha < 128 → couleur-clé (0xF81F), alpha ≥ 128 → couleur.
- **Image** : LoadArgb (décodage), Crop (ExtractSubset), Resize (bicubique/plus proche).
- **Sprite** : BuildSprite (+ frames), export C++ déterministe (PROGMEM), .gbspr round-trip.
- **Tilemap** : export C++ (bg/fg, cols/rows), .gbmap round-trip.

## Note API SkiaSharp
`Resize(SKImageInfo, SKFilterQuality)` est l'API 2.88. Si tu montes en SkiaSharp 3.x,
remplace par `SKSamplingOptions` (petit ajustement d'une ligne).

## Ce qui n'est PAS ici (et pourquoi)
L'**UI** de l'éditeur (contrôle de dessin `PixelCanvas`, vue `SpriteEditor`,
`TilemapGrid`, `TilemapEditor`) est de l'Avalonia que je ne peux ni compiler ni
tester dans mon environnement. Elle consommera cet AssetService et convertira
`SKBitmap` → image Avalonia pour l'affichage. À faire avec ton compilateur dans
la boucle (lots 12 & 14).
